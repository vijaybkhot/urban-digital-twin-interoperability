## Release boundaries

The `v0.1.0` release represents a reproducible research-prototype baseline. It
does not claim:

- production readiness or a hosted public application;
- an official FEMA determination, live flood condition, route safety, facility
  availability, or emergency guidance;
- a real reconstruction backend or generated project reconstruction;
- a real AI/LLM provider;
- complete OpenStreetMap coverage;
- LSU ownership, sponsorship, certification, or endorsement;
- npm publication, a DOI, or a peer-reviewed project publication.
